# Simple Alarm

シンプルな UI のブラウザ向けアラームアプリです。HTML / CSS / JavaScript のみで動作し、サーバーやビルドは不要です。

## 使い方

`index.html` をブラウザで開くだけで利用できます。

- 時刻を選んで「セット」を押すとアラームが登録されます
- 設定時刻になるとビープ音が鳴ります
- 「停止」ボタンで音を止められます
- 一覧の「削除」でアラームを取り消せます
- 設定内容は `localStorage` に保存されます

## ファイル構成

- `index.html` ― マークアップ
- `style.css` ― スタイル
- `app.js` ― ロジック
